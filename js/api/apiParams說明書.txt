jobs:{

GET {{host}}/users?filter[username]=admin
搜尋 username = "admin"

###
GET {{host}}/users?filter[username][$contains]=st120
搜尋 username 含有 "st120"

###
GET {{host}}/users?
  filter[createdAt][$gte]=2022-08-05 08:52:52&
  filter[createdAt][$lt]=2022-08-05 08:52:53
搜尋 createdAt >= 2022-08-05 08:52:52 並且 createdAt < 2022-08-05 08:52:53

'jobs.department'代表巢狀，取得jobs，jobs下要取得department
使用'jobs.department'的話'jobs'就可以省略

{
  populate: 'jobs'
}
{
  populate: ['jobs']
}
{
  populate: ['jobs', 'jobs.department']
}
"jobs"可省略
{
  populate: ['jobs.department']
}
